# Privacy Policy for ToolBox

ToolBox is built with an **offline-first, zero-telemetry, privacy-by-default** philosophy.

## 1. Local Processing
All tool operations—including image manipulation, video-to-audio extraction, audio trimming, PDF compilation and rendering, text manipulation, cryptography hashing, unit conversions, and calculations—occur **entirely on your device**.

## 2. No File Uploads
ToolBox **never transmits your files, audio, images, or documents to remote servers or cloud endpoints**. All files processed remain inside your sandbox storage and temporary cache until explicitly shared or exported by you.

## 3. Storage Access & Android Permissions
- ToolBox uses Android's modern Storage Access Framework (SAF) and native document pickers.
- The app does not request broad file storage permissions.
- Temporary files generated during file conversions (e.g. video extraction, zip archive creation) are stored in the app's private cache directory and can be cleared at any time from **Settings → Storage → Clear Temporary Cache**.

## 4. Analytics & Tracking
- No user tracking, analytics, or behavioral surveillance SDKs are included.
- No personal user identifiers or device fingerprints are collected.

## 5. Contact
For any privacy questions or concerns, file an issue on the project's repository.
